Katalog Properti Kos (Pencarian & Filter)

Menampilkan daftar properti indekos dengan dukungan query pencarian teks, filter spesifikasi, pengurutan, dan paginasi.

query Parameters
page
integer >= 1
Default: 1
Example: page=1

Nomor halaman paginasi

per_page
integer [ 1 .. 100 ]
Default: 12
Example: per_page=12

Jumlah data per halaman

q
string
Example: q=Graha Melati

Kata kunci pencarian teks bebas

lokasi
string
Example: lokasi=Sleman

Filter alamat atau wilayah kota

harga_min
integer >= 0
Example: harga_min=500000

Batas minimum tarif bulanan dasar

harga_max
integer >= 0
Example: harga_max=2000000

Batas maksimum tarif bulanan dasar

jenis
string
Enum: "putra" "putri" "campur"
Example: jenis=campur

Kategori jenis penghuni kos

fasilitas
Array of integers
Example: fasilitas=1&fasilitas=2

Array ID fasilitas (harus memiliki seluruh fasilitas terpilih)

tersedia
boolean
Example: tersedia=true

Hanya tampilkan kos yang memiliki kamar berstatus tersedia

pemilik_id
integer
Example: pemilik_id=2

Filter kos milik mitra pemilik tertentu

sort
string
Default: "latest"
Enum: "latest" "harga_asc" "harga_desc" "id_asc"
Example: sort=harga_asc

Pengurutan data katalog kos
